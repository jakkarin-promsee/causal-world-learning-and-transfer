# Planned experiments

This folder holds reproducible studies and their result documents. The Phase-1 questions are sketched in `../../ideas/stage-3-actual-experiment-1.md`; the track folders below are placeholders for designs that have not been frozen yet. Exploratory scripts live in `../toys/`, and reusable runner and policy code lives in `../reuse/`.

The `phase-1/track-*` names are document and artifact folders, not importable Python package names. A study can later put its runner and analysis files in its track folder without changing the `core` contracts.
