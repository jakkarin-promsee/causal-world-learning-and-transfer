# Track 1 Exp 01 raw schema

Both runs use `track1-exp01-raw-v1`. Each run directory has `metadata.json`, `selected_world_indices.npy`, and `episodes.jsonl`. The NumPy file is a one-dimensional `int32` array of distinct canonical dataset indices in sample order. For the long run it contains the planned full random order; only the prefix named by `completed_worlds` was executed. The JSONL file has exactly one line per completed world, ordered by `sample_position`.

Each JSONL line stores `world_index` as result metadata and has `stages.A`, `stages.B`, and `stages.C`. Each stage stores its maximum `budget`, `executed_steps`, `termination_reason` (`singleton`, `equivalent`, or `budget_exhausted`), `final_survivor_count`, `initial_uncertainty_bits` at `t=0`, `uncertainty_trajectory_bits` for `t=0..budget`, `inferred_suffix_from_step`, elapsed seconds, and actual `steps`. A step has the runner's zero-based `timestep`, one-based `action_step`, `action_id`, intervention `x` and `y` (`null` means unforced), encoded observation, survivor counts before and after, predictive entropy, observed surprisal, realized information gain, and remaining uncertainty, all in bits where applicable. Stage is the containing object key. Trajectory values after `executed_steps` are inferred constants certified by early stopping; they are not executed actions.

`metadata.json` records run name, status, start and finish UTC timestamps, actual elapsed seconds, completed world count, sampling seed and method, index file and SHA-256, numeric dataset path and world-file SHA-256, Git revision and source-file hashes, policy, `candidate_limit=null`, stage budgets, software versions, CPU device, and response-cache path. The saved indices determine the actual hidden-world sample; no world index is passed to the policy. The independent unit for later analysis is the hidden world.
